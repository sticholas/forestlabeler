# Codex Prompt Scripts

Reusable scripts for steering future Forest Labeler Codex sessions.

- `MASTER_OPERATING_SCRIPT.md`: start here for substantial work. It gives the agent the project north star, workflow priorities, architecture boundaries, data-safety rules, and quality gates.
- `FEATURE_BUILDER_SCRIPT.md`: use when implementing a specific feature or bug fix.
- `REVIEW_AND_QA_SCRIPT.md`: use when reviewing a branch, PR, diff, risky module, or release candidate.
- `ROADMAP_PLANNER_SCRIPT.md`: use when planning the next issues, branches, or product slices.

Recommended flow:

1. Feed `MASTER_OPERATING_SCRIPT.md`.
2. Feed one task-specific script.
3. Paste the exact feature, bug, review scope, or planning goal into the placeholder section.
